# ✈️ YedaTravel — Agencia de Viajes

## 📌 Descripción del proyecto

YedaTravel es un proyecto web de una agencia de viajes desarrollado utilizando HTML, CSS y JavaScript. Su objetivo es ofrecer a los usuarios una experiencia sencilla e intuitiva para descubrir destinos turísticos, consultar ofertas de vuelos, explorar paquetes de viaje y alojamientos, así como administrar sus reservas y contactar con la agencia.

El sitio web presenta una interfaz organizada por secciones, con información sobre la empresa, su misión y visión, además de formularios interactivos para facilitar la comunicación con los clientes.

## 🎯 Objetivos

Diseñar una página web atractiva para una agencia de viajes.
Mostrar ofertas de vuelos nacionales e internacionales.
Presentar paquetes turísticos y opciones de alojamiento.
Permitir a los usuarios consultar información de sus viajes.
Incorporar formularios de inicio de sesión y contacto.
Practicar el desarrollo web utilizando HTML, CSS y JavaScript.

## 🛠️ Tecnologías utilizadas

HTML5: estructura y contenido de la página web.
CSS3: diseño visual, estilos, distribución de elementos y adaptación a diferentes dispositivos.
JavaScript: interactividad, validación de formularios y gestión de eventos.
Imágenes locales y externas: recursos visuales para representar destinos, hoteles y servicios turísticos.

## 🌎 Funcionalidades principales

### ¿Quiénes somos?

Presenta información general sobre YedaTravel, incluyendo la descripción de la agencia, su misión, visión y un video relacionado con sus servicios.

### Inicio de sesión

Incluye un formulario para ingresar el correo electrónico y la contraseña del usuario.

### Ofertas de viaje

Muestra promociones y precios referenciales para destinos como:
Cusco
Ayacucho
Trujillo
Argentina
Estados Unidos

### Destinos nacionales e internacionales

Permite explorar diferentes destinos turísticos y consultar precios referenciales de vuelos nacionales e internacionales.

### Paquetes turísticos

Presenta paquetes que combinan alojamiento y vuelo, con opciones para destinos nacionales e internacionales.

### Alojamientos

Incluye información sobre hoteles, ubicaciones y precios referenciales en distintos destinos turísticos.

### Administración de viajes

Contiene un formulario para buscar un viaje mediante el código de reserva y los datos del pasajero.

### Información del viaje

Muestra un ejemplo de itinerario con destino, número de orden, horario del vuelo, aeropuertos y detalles del equipaje.

### Formulario de contacto

Permite introducir datos personales, seleccionar el tipo de documento, registrar información de contacto y enviar consultas a la agencia.

### Pie de página

Incluye el logotipo de YedaTravel, enlaces a documentos legales y accesos a redes sociales.

## 💻 Requisitos

El proyecto está organizado en secciones para facilitar la navegación y el acceso a la información.
Entre sus elementos de diseño se encuentran:
Menú de navegación con submenús.
Botón de menú hamburguesa.
Tarjetas informativas de destinos, vuelos, paquetes y hoteles.
Formularios de usuario y contacto.
Imágenes ilustrativas de destinos turísticos.
Enlaces a documentos legales y redes sociales.

## 🔒 Consideraciones importantes

Este proyecto es una implementación básica con fines educativos y de práctica del desarrollo web.

El inicio de sesión es una interfaz de demostración y no debe considerarse un sistema de autenticación seguro sin un backend.
La búsqueda de reservas utiliza información de ejemplo y no implica una conexión real con aerolíneas o sistemas de reservas.
Los precios mostrados son referenciales y no representan necesariamente tarifas disponibles en tiempo real.
Los formularios requieren la lógica correspondiente en JavaScript y, si se desea almacenar o enviar información, una integración con un backend.
Las imágenes y los enlaces externos dependen de la disponibilidad de sus respectivos sitios web.
